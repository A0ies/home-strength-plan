# Home Strength Plan

A small web app for a Tuesday/Friday home strength program: it plans each session, moves a missed session to the next day, tracks progress on the device and makes exercises harder over time.

Open it on an iPhone in Safari and choose Share → Add to Home Screen.

Exercise photos: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).
